Resumen HTML: Principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistos en la clase de programación web I, en el módulo HTML.

Conceptos principales HTML

HTTML

Lenguaje de marcado de hipertexto,es un lenguaje de marcas que se usa para estructurar sitios WEB.

Elemento HTML

Un elemento HTML es la unidad básica de estructuea y contenido en una página web, esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contendio
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqueta que se utiliza para comunicarse con el navegador através de los metadatos, permite mejorar el SEO, además se enlaza archivos externos de estilos o scripts

Etiqueta <Body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web

Contenedores semánticos

<Header> Etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, menú de navegación, nombre de la empresa, etc.
<Nav> Etiqueta utilizada para el menú de navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe haber más en la página
<Main> Etiqueta única de una página web cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido principal de nuestra página
<Section> Es una etiqueta que poco a poco se intenta que sistituya a <Div>, su uso es para divisir una página web en secciones y agrupar contenido relacionado
<Article> Es una etiqueta que se utiliza para agrupar contenido autonomo que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<Footer> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria.
<Aside> Esta etiquetra representa una sección de la página web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como : barras laterales, publicidad, enlaces a otros articulos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar en otras paginas

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/7841248681"
Este valor envía un WhatsApp a un número determinado
href="mailto:example@gnail.com"
Este enviaba un correo a un mail especifico
